# El Gran Juicio de la IA · Votación

Examen final integrador de **Ética con IA** (ISFD y T «República Federal de Alemania», El Colorado, Formosa).

Los alumnos ven las cuatro historias, marcan para cada protagonista si es responsable o no y suman puntos según el grado de responsabilidad. Se aprueba con 7 puntos. La Historia 4 queda cerrada como recuperatorio.

Los votos se guardan en una planilla de Google por medio de una aplicación web de Apps Script. La corrección y la contraseña del panel de administración viven en ese script, no en este repositorio.
